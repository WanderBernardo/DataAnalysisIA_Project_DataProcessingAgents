## 01. Create Schema:
  `What is it:` A Schema (Esquema) is a structure or blueprint that defines how data is organised, stored, and related within a system. In simple terms, a schema tells a computer what information to expect, how it should be organised, and what rules it must follow.

  `Sections:` It is important for organize the information and AI doesn't miss. In our example there are sections below, Sections below, it is based in our example in attachment, you could create news sections or model of schema.
  
      - Canonical input columns: This section identifies which columns the AI agent will receive from the original Excel or CSV file.
      
      - Sanitized output columns: This section describes how the original information should look after processing.
      
      - Sanitization rules: This is the most important operational section of your schema. It tells the AI agent exactly how to transform inconsistent or messy information into standardized values.
      
      - Quality checks: After cleaning the information, the AI agent must verify whether the results meet the requirements. Think of this section as a quality-control inspection.
      
      - Invalid handling: Sometimes the AI agent receives information that is incomplete, contradictory or impossible to interpret. This section defines what the agent must do in those situations.
